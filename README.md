# 成大演講彙整

每天兩次（06:17、14:17）自動讀成大約 120 個系所、學院、學位學程的公告，找出演講，標上參加限制，輸出成：

- `docs/lectures.ics`：Google 日曆訂閱檔
- `docs/index.html`：手機可看的演講清單，可依限制篩選

## 標籤

| 標籤 | 意思 |
|---|---|
| 【開放】 | 公告寫了歡迎全校、開放校外、免報名等 |
| 【限定】 | 公告寫了限本系、限修課學生、不開放校外等（日曆內文附原文片段） |
| 【需報名】 | 公告提到報名（可能和上面兩個同時出現） |
| 【未註明】 | 公告沒寫，通常可以直接去聽 |

## 怎麼判斷是演講

不是靠搜尋引擎。程式直接打開每個系所的公告列表，新公告一則一則讀內文：標題有演講、講座、seminar、talk、論壇、工作坊等字，或內文同時有「講者」和「時間／地點」欄位，就算演講。讀過的公告記在 `data/seen.json`，不會重讀。
